# Agent 0 Implementation Plan

**Goal:** A bounded, testable cross-document evidence execution loop.
**Architecture:** Thin session around frozen retrieval; strict action validation
and explicit state; deterministic policy first, then optional local JSON selector.
**Tech stack:** Existing Python/NumPy/Sentence Transformers, stdlib HTTP/unittest.
**Spec:** [Agent 0 design](../../agent0-minimal-harness-design.md).
**Execution:** Inline, user preauthorized continuation; no commits or pushes.

## Constraints and review focus

Preserve RAG modules/defaults, private input hashes, no dependency installation.
Review source alias collisions, pre-retrieval scope filtering, forged/unknown
citations, model JSON types/extra fields, early FINISH and denied budget calls.

## Tasks

1. Session/tools: add `src/agent/tools.py` and package, test aliases, deterministic
   IDs, scoped Dense/Hybrid/BGE, bounded lookup, empty/invalid/error statuses.
   Write tests → observe missing feature → implement → run tool tests.
2. Harness: add `actions.py,state.py,harness.py,policy.py`; test preflight,
   SEARCH/LOOKUP/FINISH, missing side, errors, invalid JSON/ID/citations and all
   three budgets. Write tests → observe failures → implement → run full suite.
3. Local selector/CLI and benchmark: strict `/api/chat` JSON with HTTP timeout,
   action-only schema; add synthetic 10-case runner and private output boundary.
   Test transport/schema/output path → run deterministic benchmark → then local
   qwen3:4b smoke/benchmark, preserving failures rather than tuning the benchmark.
4. Industrial smoke: freeze private task manifest before inference, use existing
   cached structured inputs/models, verify pre/post hashes and zero MinerU calls;
   review implementation, run compileall/full unittest/diff/privacy checks and
   update READMEs/results. No next milestone implementation.

Progress and measured results are recorded in the Agent 0 results report;
historical reports remain unchanged.
