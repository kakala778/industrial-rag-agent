# Industrial RAG Agent

## Goal

This is a learning and experimentation project to understand and build an Industrial RAG + Agent system from scratch. It is not a production system.

## Planned Pipeline

```text
Documents
→ Parsing
→ Chunking
→ Embedding
→ Retrieval
→ RAG
→ Source Citation
→ Agent
→ Evaluation
```

## Key Decisions

- Start minimal and add components only when needed.
- Do not introduce large RAG frameworks during initialization.
- Real industrial/project data will not be committed to this repository.
- The first technical milestone will be a minimal retrieval pipeline using simple test documents.

- Real industrial documents will not be uploaded.
