# Local PDF Test Documents

This folder is for public sample PDFs used to check the document loader. The
current sample is the one-page [W3C dummy PDF](https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf).

PDF files are ignored by Git. Keep this sample local and do not put teacher-
provided, industrial, private, or otherwise restricted documents here.

Run the PDF RAG demo from the repository root:

```bash
python src/pdf_rag_demo.py examples/pdf/w3c-dummy.pdf
```
